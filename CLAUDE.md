# Notes for Claude

## Copywriting requests (카피·후킹 문장 작성)
When the user asks for copy, hooks, headlines, captions, landing pages, or email subjects, use `pesona-copy-bank/` as the primary reference:
- `pesona-copy-bank/README.md`: PESONA workflow, situation → category finder, core principles, the brief template, and all 800 words by category.
- `00_서론_PESONA법칙.md` to `06_A_행동촉구.md`: the full word list with tips and 2400 numbered examples (0001–2400).

How to write:
1. Fill the brief in README section 4 from what the user gave you. Ask only for what is missing and actually needed.
2. Build the copy in PESONA order (Problem → Empathy → Solution → Offer → Narrow → Action), or reorder it for the medium as `00_서론` describes.
3. For headlines, give 10+ candidates. Name the pattern behind each one (word + example number, e.g. "자주 하는 실수 / 0007") and check it against the 8 headline elements.
4. Write in Korean unless the user asks otherwise. Adapt the patterns to the user's situation; don't copy book examples verbatim.
